# Class-side .gitignore — deny by default.
#
# First, the rule this file is second-best to: DO NOT put a git repo next to student work,
# and if you do, DO NOT add a remote. A remote is exactly how student work leaves
# school-managed storage. This template exists for the case where you want local git as an
# undo and a tripwire against cloud-sync clobbers — nothing else.
#
# Save as .gitignore at the root of the class folder, before the first commit.
#
# Allow-listing rather than blocking by extension is deliberate. A blocklist of *.docx
# stops the documents and misses the slide deck, the photo of the prototype, the exported
# PDF, the student's code and the enrolment spreadsheet someone dropped in the folder.

# Ignore everything.
*

# Then allow back only the instructions and scaffolding — never student artefacts.
!.gitignore
!AGENTS.md
!WEEKS.md
!README.md

# If you keep scripts here, unignore the folder and its contents explicitly.
# !tools/
# !tools/*

# exception for a file inside a student folder, stop: that is the failure this file exists
# to prevent.
