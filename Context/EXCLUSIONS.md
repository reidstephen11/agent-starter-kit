# What the agent must never produce

Read this **before generating any pedagogical content.**

These are excluded precisely because they are what an agent reaches for by default: they
are common in its training data, they sound professional, and several of them are still
widely believed. Without this list you will get them, and they will pass a quick read.

Each exclusion names a replacement — the point is to redirect, not just to forbid.

| Never | Instead |
|---|---|
| Learning styles / VAK ("visual learners", "auditory learners") | Choose the representation the *content* demands. Dual coding — words plus a relevant graphic — helps everyone. |
| The learning pyramid / "people remember 10% of what they read" | Retrieval practice, spaced practice, and testing effect, which have actual evidence. |
| Multiple intelligences as a basis for differentiation | Differentiate by prior knowledge, scaffolding and support, not by an alleged intelligence type. |
| "Digital natives" — students inherently good with technology | Teach the specific skill. Fluency with a social app predicts nothing about file systems, spreadsheets or code. |
| Neuromyths: left/right-brain learners, 10% of the brain, "brain breaks" framed as neuroscience | Cognitive load, working memory limits, worked examples. |
| AI-detection tools or claims that writing "looks AI-generated" | Process evidence: drafts, version history, checkpoints, conversation about the work. Never accuse a student. |
| Scripted teacher talk — word-for-word dialogue for the teacher to read out | Specify the intent, the key question, the checkpoint. Leave the delivery to the teacher. |
| Invented statistics, effect sizes, or citations | Cite only what is in the context pack or a source you can point to. If you don't have one, say the claim is reasoned rather than evidenced. |
| Curriculum wording written from memory | Quote from `Context/curriculum/`. Nothing else. |
| Fabricated confidence about what will work in this classroom | Say what the trade-off is and let the teacher decide. |

## When something asks for an excluded thing

Do not silently comply, and do not silently refuse. Say which exclusion applies and why in
one sentence, offer the replacement from the same row, and let me overrule you. I may have a
reason — quoting a myth in order to take it apart in an AI-literacy lesson is a legitimate
use, not a violation.

This applies to what I tell you as much as to what you generate. If I ask you to record a
belief this list excludes — into this file, into `teaching-beliefs.md`, or anywhere else in
the context pack — say so before you write it, and give me the replacement. A contradiction
saved into the pack is read at the start of every future session and quietly cancels the rule
it contradicts. If I confirm after that, record it as my stated preference and note in the
same line that it conflicts with this list.
