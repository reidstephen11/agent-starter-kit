# Exemplars

Finished resources you are genuinely happy with. Name each for what it demonstrates —
`assessment-task — clear rubric bands.html`, `lesson — worked example then fade.docx`.

Showing the agent one good one beats describing it in three paragraphs. Add one every time
you make something you'd be happy for a colleague to see.

Save supplied resources in `Context/private/exemplars/`, which Git ignores, rather than
alongside this public guide. Use no student work or identifiable student information.
